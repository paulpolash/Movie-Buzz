## MovieBazz 🎬

MovieBazz is an Android movie discovery app built with Kotlin and Jetpack Compose. It helps users explore movies, view movie details, and discover popular titles through a modern interface.

## ✨ Features

- **Home Screen:** Browse featured and popular movies.
- **Movie Details:** View detailed information about selected movies.
- **Search Movies:** Find movies by title.
- **Favorites:** Keep track of favorite movies.
- **Modern UI:** Built with Jetpack Compose and Material 3.

> Only keep the features that are currently implemented.

## 🛠️ Tech Stack

- **Language:** Kotlin
- **UI:** Jetpack Compose, Material 3
- **Architecture:** MVVM with Clean Architecture principles 
- **Asynchronous Programming:** Kotlin Coroutines and Flow 
- **Networking:** Retrofit 
- **Image Loading:** Coil 
- **Navigation:** Navigation Compose
- **Data Storage:** Room or DataStore

## 🚀 Getting Started

1. Clone this repository.
2. Open the project in Android Studio.
3. Sync the Gradle files.
4. Configure any required API keys.
5. Build and run the app on an emulator or Android device.
